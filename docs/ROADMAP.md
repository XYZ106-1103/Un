## PHASE 1 — 프로젝트 기반 ✅

## PHASE 2 — 메인 메뉴 및 필드 ✅

**결과물**
- **메인 메뉴** (`scenes/MenuScene.ts`): 타이틀 → NEW GAME / CONTINUE / SETTINGS / CREDITS. 저장이 있으면 CONTINUE에 커서, 없으면 비활성 + 안내. 커서·결정·취소 효과음, 페이드 전환, 타이틀 곡.
- **저장** (`systems/SaveSystem.ts`, `game/GameState.ts`): 슬롯 3개, 각 슬롯에 수동 기록 + 백업 + 자동 저장. 맵 이동 시 자동 저장, 도장 책상에서 수동 기록. 손상 시 백업 복구(읽기는 데이터를 바꾸지 않고, 덮어쓸 때 손상본을 격리). 미래 버전 감지. 게임 오버 후 "마지막 기록에서"는 수동 기록 기준.
- **이름 입력** (`ui/NameEntryPanel.ts`): 숨겨진 DOM 입력으로 한글 IME·모바일 키보드 지원, 특정 이름에 대한 반응(`data/story/names.json`, 일부 이름은 거절).
- **설정** (`ui/MenuPanels.ts` SettingsPanel): 볼륨 4종, 글자 속도, 배율 모드, 화면 흔들림, 번쩍임 줄이기, FPS, 터치 버튼, 언어, 기본값 복원. 메뉴와 게임 중 모두 사용.
- **크레딧**: 스크롤 크레딧 (`data/story/credits.json`, Galmuri OFL 표기 포함).
- **필드** (`scenes/WorldScene.ts`, `entities/Player.ts`, `entities/NPC.ts`):
  - 맵은 ASCII 레이아웃 + 범례 JSON (`data/maps/*.json`): 타일·장식·충돌·숨은 통로·NPC·조사 오브젝트·출입구·트리거·세이브 포인트·랜덤 인카운터·음악·환경 연출
  - 4방향 이동, 달리기(취소 키), 축별 충돌로 벽 따라 미끄러지기, 모서리 보정(1칸 문 통과), 짧게 톡 눌러 방향 전환
  - NPC 행동(제자리·두리번·배회), 말 걸면 플레이어 쪽으로 돌아봄
  - 조사 아이콘 HUD, 맵 이름 배너, 작은 방 자동 중앙 정렬, 먼지·빛줄기 환경 연출
  - 1회성 트리거(세이브에 기록), 조건부 출입구·NPC·오브젝트, 비밀 이벤트(3번 조사하면 단추 발견), 숨은 통로(상자 더미 사이)
- **게임 중 메뉴** (`ui/PauseMenu.ts`): 주머니(사용/살펴보기/내려놓기/정리), 상태(능력치·장비·플레이 시간), 설정, 타이틀로(확인).
- **터치 컨트롤** (`ui/TouchControls.ts`): 십자 패드 + Z/X/C, 멀티터치, 장면별 표시 방식(필드: 전체, 전투: 회피 중 십자 패드만, 메뉴: 직접 탭).

## PHASE 3 — 대화 시스템 ✅

**결과물**
- **스크립트 VM** (`systems/DialogueSystem.ts`): 대사·선택지(조건부 선택지)·분기·`goto`·`call`·플래그 변경·명령. Phaser 없이 단위 테스트.
- **조건식** (`systems/script/Condition.ts`): `flag:met && rel:ledger > 2 || !item:thread`, 괄호, 비교 연산. 모든 콘텐츠 조건은 로딩 검증에서 파싱됨.
- **리치 텍스트** (`systems/text/RichText.ts`): `{player}`, `{item|을/를}`(받침에 따른 한국어 조사 자동 선택), `{w=300}` 멈춤, `{s=0.5}` 속도, `{c=amber}` 색, `{shake}`/`{wave}` 글자 효과, `{face=sad}` 표정, `{sfx=...}`.
- **대화창** (`ui/DialogueUI.ts`): 타이핑(설정 속도 4단계), 구두점 뒤 자연스러운 쉼, 건너뛰기, 넘김 표시, 초상화 + 표정, 이름표(캐릭터 색), 캐릭터별 보이스 블립, 플레이어 위치에 따라 위/아래 배치, 선택지 패널, 직접 구현한 줄바꿈(긴 한국어 단어는 음절 단위 분리).
- **명령**: `sfx`, `music`(크로스페이드), `shake`, `flash`(번쩍임 줄이기 시 페이드로 대체), `wait`, `face`, `item.add/remove`, `buttons`, `heal`, `relation`, `battle`(결과를 `flag:last_battle`에 기록), `save`, `map`, `npc.hide/show/face/move`, `player.face`, `end`.
- **콘텐츠**: 레저(초상화 5표정), 오프닝, 투입구 바닥·분류실·우산꽂이 숲 입구의 대사. 레저는 플레이어가 이어폰을 놓아줬는지/치웠는지 기억하고 반응.

## PHASE 4 — 전투 시스템 ✅

**결과물**
- **전투 규칙** (`systems/BattleSystem.ts`): 적 상태 변수, ACT(조건부 목록, 필요 조건/거절 문구, 반복 반응), 놓아주기 조건, 타이밍 정확도 기반 피해, 도망 확률, 보상(놓아주면 절반), 조우·놓아줌·치움 기록. 단위 테스트.
- **탄막** (`systems/BulletSystem.ts`): 객체 풀(free-list, 발사마다 할당 없음) + 에미터 9종: 직선·원형(빈틈 있는 수축 고리)·방사·회전·낙하·추적·연사·시퀀스(페이즈)·복합(병렬). 적 상태 조건으로 패턴 페이즈 전환. 탄막은 전투 상자 안으로 마스킹.
- **전투 화면** (`scenes/BattleScene.ts`, `ui/BattleUI.ts`, `entities/Soul.ts`, `entities/Enemy.ts`): 보관표 모양 명령 버튼(CLEAR/ACT/POCKET/LET GO), 크기가 변하는 전투 상자, 타이핑 텍스트, 적 말풍선, 타이밍 미터, 피해 숫자·HP 바·흔들림, 영혼 이동(취소 키로 정밀 이동)과 무적 깜빡임(번쩍임 줄이기 대응), 놓아주기/치우기 연출, 승리·도망·패배(보관표가 찢어짐) → 게임 오버.
- **적 2종**: 꼬인 이어폰(풀어주기 2회로 놓아주기, 잡아당기면 화남 → 다른 패턴), 영수증 유령(읽기 → 맞히기로 기억을 되찾아 놓아주기, 구기면 화남).
- **랜덤 인카운터**: 맵별 평균 걸음 수, 조건부 활성화.

## 완료 기준 통과 기록 (PHASE 2–4)

- `npm run typecheck` 통과
- `npm test`: 69개 통과 (15개 파일) — 조건식, 게임 상태, 저장(백업 복구·우선순위), 인벤토리, 리치 텍스트·조사, 대화 VM, 전투 규칙, 픽셀아트 해석기, **출하 콘텐츠 전체 교차 검증**(깨진 참조를 일부러 넣어 검출되는 것도 확인)
- `npm run build` 통과 (앱 JS 70 KB gzip + Phaser 332 KB gzip)
- `npm run smoke` 통과 — 5개 화면 레이아웃 + 데스크톱 전체 여정(새 게임 → 이름 → 오프닝 → 비밀 → 맵 이동/자동 저장 → 레저 선택지 → 수동 저장 → 일시정지 → ACT·놓아주기 전투 → 치우기 전투 → 레저의 반응 → 게임 오버 → 재시작 → 새로고침 후 CONTINUE → 맵 왕복 누수 검사 → 설정 저장) + 휴대폰 터치 여정(탭으로 메뉴·대화, 십자 패드 이동), 콘솔 오류 0건

**검증 중 찾아 고친 결함**: 1칸 문에 들어가지 못함(모서리 보정), 물체에 붙어 서도 조사가 안 됨(판정 경계 1px), 짧은 방향 입력 무시, 스크립트 중 열린 저장 패널이 입력을 못 받음, 적 말풍선 재사용 시 크래시, 전투마다 리스너·마스크 누적(누수), 폰트 아틀라스 확장 후 기존 글자가 깨짐, 슬롯 선택 강조색 누락, 먼지 효과가 맵 밖에 그려짐, 게임 오버 후 재시작이 자동 저장을 불러옴.

## 알려진 한계

- **대사·아이템·적 텍스트는 한국어만** 있습니다(UI 문자열은 한/영). 콘텐츠 현지화는 PHASE 8.
- **소리는 귀로 검증하지 않았습니다.** 음악·효과음·보이스 코드는 실행되고 AudioContext가 동작하는 것까지 자동 확인했습니다.
- 타이틀 로고·타이틀 배경은 여전히 임시입니다(화면에 표시). 나머지 아트 10종은 직접 그린 실제 아트(wip).
- 적 스프라이트(40×40)가 화면 대비 작은 편입니다. PHASE 5에서 크기·프레임 수를 늘릴 예정입니다.
- 플레이 가능한 범위: 방 3개, 적 2종. 우산꽂이 숲 본편과 미트·브롤리 경은 PHASE 5–6. 경로 끝 표지판이 현재 범위의 끝을 알립니다.
- 단추(화폐)를 모을 수 있지만 상점은 아직 없습니다.
- 키 재배치 UI는 없습니다(데이터 구조는 준비됨).
- 스모크 테스트는 약 10회 실행 중 1회, 원인을 특정하지 못한 시간 초과가 있었습니다(이후 5회 연속 통과). 재발 시 로그로 추적 필요.
- 맵은 Tiled 대신 자체 ASCII 형식입니다(리뷰·diff가 쉬움). 필요하면 Tiled 가져오기를 추가할 수 있습니다.
