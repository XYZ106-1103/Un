> 다음 작업자가 이 파일만 읽고 이어서 작업할 수 있도록 유지합니다.

기간은 1인 풀타임 기준 추정치입니다. 아트·음악 제작은 병행 트랙입니다.

## PHASE 1 — 프로젝트 기반 구축 ✅

**결과물**
- Vite 7 + TypeScript 5.9(strict) + Phaser 3.90 프로젝트, 상대 경로 정적 빌드
- 480×270 네이티브 렌더링, 기기 픽셀 기준 정수 배율(auto / pixel-perfect / fit), 리사이즈·회전·DPR·전체화면 대응, 노치 안전 영역, 세로 모드 회전 안내
- 한글 픽셀 텍스트 파이프라인 (Galmuri → 런타임 1비트 비트맵 아틀라스)
- 코어 서비스: 타입 이벤트 버스, 안전한 저장소 + 버전 봉투, 설정, 입력 매핑(키보드·게임패드·터치), 오디오 버스 + 합성 효과음, UI 문자열(ko/en)
- 에셋 매니페스트 + 플레이스홀더 파이프라인 + 상태 리포트
- 씬: Boot → Preload(실제 진행률) → Title(PHASE 1판) → DevRoom(개발용 렌더링 테스트) / Overlay(F3 디버그, FPS)

**완료 기준 통과 기록**
- `npm run typecheck` 통과
- `npm test` 37개 통과 (7개 파일)
- `npm run build` 통과 (앱 JS 17 KB gzip + Phaser 332 KB gzip)
- `npm run smoke` 통과: 1920×1080, 1536×864@1.25, 1366×768, 844×390@3(터치), 390×844@3(터치) — 배율·중앙 정렬·입력·설정 저장·씬 5회 왕복 누수 없음·콘솔 오류 0
- 개발 서버(`npm run dev`)에서도 스모크 통과

**알려진 한계 (의도된 것)**
- 타이틀의 로고·배경, 주인공, 타일은 플레이스홀더입니다 (화면에 "임시 아트" 표시).
- Title에서 확인을 누르면 개발용 렌더링 테스트 룸으로 갑니다. 메인 메뉴는 PHASE 2입니다.
- 효과음은 코드 실행과 AudioContext 동작까지 자동 검증했고, 실제 소리의 질은 사람이 들어 확인해야 합니다.
- Canvas 렌더러 폴백(WebGL 미지원 기기)에서는 텍스트 틴트 색이 적용되지 않습니다(흰색 표시). WebGL 미지원 환경은 드물어 PHASE 8에서 재평가합니다.
- 비정수 배율 모드에서는 픽셀 폭이 약간 불균일합니다(설정에서 pixel-perfect 선택 가능). PHASE 8에서 "sharp bilinear" 후처리를 검토합니다.

## PHASE 2 — 메인 메뉴 및 필드 (다음 작업)

**작업 목록**
1. `game/GameState.ts` — 상태 모델(이름, HP, 위치·맵, 플래그, 관계, 인벤토리, 플레이 시간), 기본값, 검증 함수 + 단위 테스트
2. `systems/SaveSystem.ts` — 슬롯 3개 + 자동 저장 슬롯, `VersionedStore` 기반, 손상 시 백업에서 복구, 미래 버전 안내
3. `scenes/MenuScene.ts` — TitleScene을 발전: NEW GAME / CONTINUE(저장 없으면 비활성 + 이유 표시) / SETTINGS / CREDITS, 커서 이동 애니메이션과 효과음, 이름 입력 화면(한글 입력 포함)
4. `ui/SettingsUI.ts` — 볼륨 4종, 텍스트 속도, 배율 모드, 흔들림, 플래시 완화, FPS 표시, 터치 컨트롤
5. 크레딧 화면 (Galmuri OFL 표기 포함)
6. Tiled 맵 파이프라인: `data/maps/*.json`(배경, 타일, 오브젝트, NPC, 충돌, 이벤트, 출입구, 음악) + 맵 데이터 검증
7. `scenes/WorldScene.ts`, `entities/Player.ts`(4방향 이동, 타일 충돌, 달리기), `entities/NPC.ts`(대기·배회·고정)
8. 상호작용: 조사 가능 오브젝트, NPC 말 걸기(대화 시스템 전까지는 단순 텍스트 박스), 숨겨진 통로, 맵 전환 페이드, 세이브 포인트(레저의 도장 책상)
9. 터치 가상 패드 (`InputSystem.setVirtual` 이미 준비됨)
10. 첫 실제 맵: 분류실(0장) — 아트가 없으면 플레이스홀더 타일로, 명시적으로 표시

**완료 기준**
- 새 게임 → 이름 입력 → 분류실 탐험 → 세이브 → 새로고침 → CONTINUE로 같은 위치 복귀
- 손상된 세이브를 넣어도 메뉴가 열리고 안내 메시지 표시
- 스모크 테스트에 메뉴·저장·이동·맵 전환 시나리오 추가, 모든 해상도 통과
